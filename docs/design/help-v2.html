Getting startedAan de slag

Theme Options is the control panel of the theme. You find it in the dashboard menu on the left.Theme Options is het bedieningspaneel van het thema. U vindt het links in het menu van het dashboard.

How to use itZo gebruikt u het

  1. Go to Dashboard → Theme Options.
  2. Choose a section in the menu on the left (on a phone: at the top).
  3. Change a switch or a field. A bar appears at the bottom: You have unsaved changes.
  4. Click Save changes. The change is live right away — the cache is cleared automatically.
  1. Ga naar Dashboard → Theme Options.
  2. Kies links een onderdeel in het menu (op een telefoon: bovenaan).
  3. Wijzig een schakelaar of een veld. Onderaan verschijnt een balk: You have unsaved changes.
  4. Klik op Save changes. De wijziging staat direct online — de cache wordt automatisch geleegd.

Changed your mind? Click Discard in the bottom bar to undo all unsaved changes.Toch niet? Klik op Discard in de balk onderaan om alle niet-opgeslagen wijzigingen ongedaan te maken.

Effects and sections that apply to the whole website.Effecten en onderdelen die voor de hele website gelden.

Open in Theme OptionsOpenen in Theme Options

What each setting doesWat elke instelling doet

Animations
Motion effects on the whole website: elements that fade in while scrolling, images that reveal, zoom on hover. Turn it off for a calm, static website.Bewegingseffecten op de hele website: elementen die invloeien tijdens het scrollen, afbeeldingen die verschijnen, zoom bij aanwijzen. Projects
Shows everything related to projects. When off, the projects page, the project sections and the menu links are hidden. Project pages show a “page not found” (404) to visitors and are removed from the sitemap. Nothing is deleted — turn it on again and everything is back.Toont alles wat met projecten te maken heeft.   2. Laat beide schakelaars aan staan (aanbevolen).

MaintenanceOnderhoud

Shows a holding page to visitors while you work on the website.Toont bezoekers een tijdelijke pagina terwijl u aan de website werkt.

Open in Theme OptionsOpenen in Theme Options

What each setting doesWat elke instelling doet

Maintenance mode
Visitors see a holding page in the style of the website. Google is told the site is temporarily unavailable, so rankings are not harmed. Logged-in administrators always see the normal website.Bezoekers zien een tijdelijke pagina in de stijl van de website. Google krijgt te horen dat de site tijdelijk niet beschikbaar is, dus de posities in Google blijven behouden. Ingelogde beheerders zien altijd de normale website.
Heading & Text
The title and text on the holding page. Logo, phone and e-mail are added automatically.De titel en tekst op de tijdelijke pagina. Logo, telefoon en e-mail worden automatisch toegevoegd.
Client preview link
A secret link to share with someone without an account. Whoever opens it sees the real website for 7 days. Click Copy to copy it.Een geheime link om te delen met iemand zonder account. Wie de link opent, ziet de echte website 7 dagen lang. Klik op Copy om hem te kopiëren.
New link
Makes a new preview link. The old link stops working immediately.Maakt een nieuwe voorbeeldlink. De oude link werkt direct niet meer.

How to use itZo gebruikt u het

  1. Go to Theme Options → Maintenance.
  2. Turn on Maintenance mode and check the heading and text.
  3. Click Save changes. The status card on the Overview turns red.
  4. Want someone to see the website? Copy the Client preview link and send it.
  5. Finished? Turn maintenance mode off and save.
  1. Ga naar Theme Options → Maintenance.
  2. Zet Maintenance mode aan en controleer de titel en tekst.
  3. Klik op Save changes. De statuskaart op het Overzicht wordt rood.
  4. Wilt u dat iemand de website bekijkt? Kopieer de Client preview link en stuur die door.
  5. Klaar? Zet de onderhoudsmodus uit en sla op.

To see the holding page yourself, open the website in a private window (you are logged in, so you see the normal website).Wilt u de tijdelijke pagina zelf zien? Open de website in een privévenster (u bent ingelogd en ziet dus de normale website).

Do not forget to turn maintenance mode off when the website is ready.Vergeet niet de onderhoudsmodus uit te zetten zodra de website klaar is.

TrackingTracking

A place for extra third-party code, such as a marketing pixel. Every snippet only runs after the visitor accepted cookies.Een plek voor extra code van derden, zoals een marketingpixel. Elk stukje code werkt pas nadat de bezoeker cookies heeft geaccepteerd.

Open in Theme OptionsOpenen in Theme Options

What each setting doesWat elke instelling doet

In <head> / After <body> / Before </body>
Three places in the page. The provider of the code tells you where to paste it.Drie plekken in de pagina. De aanbieder van de code vertelt u waar u die moet plakken.
Consent category
Choose the cookie category of each snippet: Functional, Preferences, Statistics or Marketing. The code only runs when the visitor accepted that category.Kies de cookiecategorie van elk stukje code: Functioneel, Voorkeuren, Statistieken of Marketing. De code werkt alleen als de bezoeker die categorie heeft geaccepteerd.

How to use itZo gebruikt u het

  1. Install a cookie plugin first (for example Complianz).
  2. Go to Theme Options → Tracking.
  3. Paste the code in the right place and choose its category.
  4. Click Save changes.
  1. Installeer eerst een cookieplugin (bijvoorbeeld Complianz).
  2. Ga naar Theme Options → Tracking.
  3. Plak de code op de juiste plek en kies de categorie.
  4. Klik op Save changes.

Without a cookie consent plugin, the snippets are never printed. This protects you under privacy law (GDPR).Zonder cookieplugin wordt de code nooit geplaatst. Zo voldoet u aan de privacywet (AVG).

Google Analytics and Search Console are managed in Site Kit by Google — do not add them here.Google Analytics en Search Console beheert u in Site Kit by Google — voeg ze hier niet toe.
